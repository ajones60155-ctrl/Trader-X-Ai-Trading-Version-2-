## Quick Start

### Option 1 – GitHub Codespaces (recommended, zero setup)

Click the badge above. The server starts automatically and the dashboard opens in a preview tab.

### Option 2 – Run locally

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Start the server
python main.py
```

Then open **http://localhost:5000** in your browser.

> Set `FLASK_DEBUG=1` to enable auto-reload during development.
